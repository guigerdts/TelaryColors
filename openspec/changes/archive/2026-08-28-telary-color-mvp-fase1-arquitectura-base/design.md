# Design: Telary Color MVP Fase 1 — Base Architecture

## Technical Approach

Modular monolith backend (`app/{core,db,modules/*}`, each module owns `models.py`+`schemas.py`+`router.py`) over SQLite/SQLAlchemy 2.0, one initial Alembic migration importing all metadata, JWT auth (PyJWT HS256 + bcrypt direct) via DI, single-origin frontend (React+Vite+Tailwind) served by FastAPI at `/`, REST under `/api/v1/`. Backend runs `python -m uvicorn app.main:app` from the project venv (PATH `uvicorn` is a broken Termux binary). Maps 1:1 to proposal approach and specs (base/auth/users/pantone-colors/formulas/designs/access-logs).

## Architecture Decisions (ADRs)

| # | Decision | Options (tradeoff) | Choice |
|---|---|---|---|
| 1 | Auth stack | passlib+jose (unmaintained, breaks w/ bcrypt 4.x) vs PyJWT+bcrypt direct | **bcrypt direct**. Few deps, modern. |
| 2 | Deployment | separate servers+CORS vs single-origin | **Single-origin**; FastAPI serves `frontend/dist`, no CORS (LAN one URL). |
| 3 | Token store | httpOnly cookie (XSS-safe, CSRF risk, non-browser LAN) vs localStorage | **localStorage** + `Authorization: Bearer` for LAN MVP; sim; documented tradeoff (XSS). |
| 4 | Ingredient units | free text w/ suggestions vs enum `g\|kg` + auto-convert | **enum + app-level normalize** to grams on read (1000 g=1 kg). |
| 5 | Decimal storage | float vs NUMERIC/Decimal | **SQLite `NUMERIC` + Python `Decimal`** — no FP loss; spec "0.001 kg". |
| 6 | Designs 1–7 cardinality | DB CHECK (impossible cross-row) vs app-level in tx | **App-level inside transaction**; DB `unique(design_id,pantone_color_id)`; UI disables 8th. |
| 7 | Module layout | flat `app/` vs modular vs hexagonal | **Modular monolith** (IMPLEMENTACION §9; hex overkill for MVP, flat violates independence). |
| 8 | Time/datetime | naive vs UTC | **UTC** `datetime.now(timezone.utc)`. |
| 9 | SQLite concurrency | delete-journal vs WAL | **WAL** pragma (LAN multiuser reads + one writer). |
| 10 | Seed creds | env-configured vs hard default | **env first, secure default fallback** `admin`/`telary-admin` (flag: override in prod). |

### Data Flow

```
Browser ──/api/v1──▶ FastAPI router ──DI get_db──▶ SQLAlchemy session ──▶ SQLite (WAL)
   ▲   ◀─JSON──            │  security.py (JWT)    module service: audit action
   └──── static / (SPA dist)                     └──▶ access_logs insert in same tx
```

## Data Model (7 tables, SQLAlchemy 2.0 typed `Mapped`)

`users(id, username unique, full_name, password_hash, role, last_access_at, created_at)`; `access_logs(id, user_id FK→users, timestamp, action)`; `pantone_colors(id Unique, code unique+indexed, gamut default 'C', paint_type enum reactiva|pigmento, created_at)`; `formulas(id, pantone_color_id FK, name, notes, created_by FK, created_at, updated_at)`; `formula_ingredients(id, formula_id FK cascade, colorant, quantity Numeric, unit enum g|kg)`; `designs(id, name unique, paint_type enum, created_by FK, created_at, updated_at)`; `design_colors(id, design_id FK cascade, pantone_color_id FK, UniqueConstraint(design_id,pantone_color_id))`.

SQLite specifics: `PRAGMA foreign_keys=ON` (FK enforcement), WAL, `NUMERIC` decimals, UTC datetimes. Alembic `env.py` imports `app.db.base.Base` → all module models; one autogenerated `0001_initial`; `upgrade head`; DB at `backend/data/app.db` (gitignored).

## API Surface (`/api/v1/`)

| Endpoint | Auth | Codes | Shape |
|---|---|---|---|
| `POST /auth/login` | public | 200/401 | OAuth2 form → `{access_token, token_type}` |
| `GET /auth/me` | any authed | 200/401 | user profile |
| `GET/POST /users` | admin | 200/201/403 | list / create |
| `PATCH /users/{id}` (role) | admin | 200/403 | role change |
| `GET /pantone-colors?q=` | authed | 200 | list/search (prefix, case-insens) |
| `POST/GET/PATCH/DELETE /pantone-colors/{id}` | authed | 201/200/409/404 | CRUD |
| `POST /formulas` `GET/PATCH/DELETE /formulas/{id}` | authed | 201/200/404 | nested ingredients |
| `POST /designs` `GET/PATCH/DELETE /designs/{id}` | admin|operator | 201/200/422/409/404 | colors 1–7 |
| `GET /access-logs` | admin | 200 | audit read |

Unit conversion: store `Decimal(quantity, unit)` with unit; **normalize to grams in API response** (`quantity_g = q * 1000 if unit=='kg'`), original unit preserved. Single conversion point `formulas/schemas.py:IngredientOut`.

## Auth Flow (login incl. audit + last_access)

```
UI ──POST /auth/login (form)──▶ auth.router
  deps: OAuth2PasswordRequestForm   validate 72-byte password
  security.verify_password (bcrypt) ──✗──▶ 401
  ✔ update users.last_access_at (UTC)
  insert access_logs(user_id, action='login')
  commit (same tx) → `create_access_token(sub, exp=12h)` → 200 {token}
```

`GET /auth/me`: `get_current_user` decodes HS256, checks `exp`, 401 on missing/invalid/expired. `require_roles('admin')` → 403 for operator on `/users`.

## Frontend

`src/{api,components,pages,router,auth,hooks}`; Vite dev proxy `/api`→`:8000`, prod served by FastAPI. Router: public Login; guarded routes (Search, Pantone, Formulas, Designs, Admin Users) via `ProtectedRoute` (no token → redirect). Api client attaches `Authorization: Bearer`, on 401 clears token + redirects login. PWA manifest+icons only (no SW — HTTP LAN). Pages: Login, Search (pantone→formula), Pantone CRUD, Formulas, Designs (1–7 picker, disables 8th), Admin Users (Spanish UI).

## Sequence: Design create with 1–7 validation

```
UI → POST /designs {name, paint_type, color_ids[1..7]}
 → validate name unique, paint_type enum, 1≤len(color_ids)≤7 (422 Spanish msg)
 → open tx; assert all pantone ids exist; delete stale design_colors; insert new link rows
 → insert access_log(create/update) → commit (app-level cardinality + DB unique pair)
 → 201/200 (Spanish error if 0 or >7 or dupes)
```

## Sequence: Formula create with nested ingredients

```
UI → POST /formulas {pantone_color_id, name, notes, ingredients[{colorant,qty,unit}]}
 → validate pantone exists; validate unit enum + Decimal quantity
 → insert formula + formula_ingredients (cascade FK) → access_log(create) → commit → 201
```

## Sequence: Pantone search

```
UI (debounce 250ms) → GET /pantone-colors?q=221 → router filter code.ilike('221%') on indexed column → 200 list → render
```

## Key Learnings

1. PATH `uvicorn` is a broken Termux stub — the project must boot only via `python -m uvicorn` from the venv.
2. `passlib` is unmaintained and incompatible with bcrypt 4.x, so bcrypt must be hashed directly.
3. SQLite cannot CHECK cross-row counts, so the 1–7 design color cardinality is enforced at the application layer inside a transaction.
4. `python-multipart` is missing globally and is required for the OAuth2 password form endpoint, so it must be pinned.
5. bcrypt truncates past 72 bytes silently, so passwords are length-validated at the schema level before hashing.
